# dev-setup-windows

The Windows counterpart of [dev-setup-chromebook](https://github.com/dhouse109/dev-setup-chromebook):
the same development environment, flags and features on four Windows laptops, with a Windows-host half
(PowerShell) and the bundle's bash scripts running inside WSL 2.

**Status: planning.** Nothing is built yet.
